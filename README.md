# Ayok Fountain Academy Website

Welcome to the official website project for **Ayok Fountain Academy**, a modern, responsive, and accessible educational website built with HTML, CSS, and JavaScript. This project aims to showcase the school's mission, curriculum, extracurricular activities, and admission information.


## 🌐 Technologies Used

- **HTML5** – Semantic structure and accessibility  
- **CSS3** – Custom styles and responsive layout  
- **RemixIcons** – Icon library  
- **Swiper.js** – Carousel/slider for curriculum section  
- **JavaScript** – Interactivity (theme toggle, video controls, mobile navigation)


## 🧰 Features

- ✅ Fully responsive layout
- 🌗 Dark/light mode toggle
- 🎥 Embedded video section
- 🖼️ Swiper-based curriculum slider
- 📲 Social media links
- 🧭 Sticky header with navigation

## 🚀 How to Use

1. **Clone this repository**  
   ```bash
   git clone https://github.com/nyeliep/afa.git
   ```

2. **Navigate into the folder**  
   ```bash
   cd afa
   ```

3. **Open `index.html` in your browser**  
   Or serve using a local server like Live Server (VS Code extension).
